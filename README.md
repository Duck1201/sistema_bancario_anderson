## Como usar o programa
<p>O programa já está compilado, para usar basta executar o binário <b>programa</b>.
O binário foi compilado no kernel Linux, e já está com as permissões de execução setadas,
então será bem fácil roda-lo.</p>

<hr>

### Passo a passo
Para executar acesse algum diretorio do sistema linux que o seu usuário tenha permissões, por exemplo: <b>$user/</b>, e rode os comandos abaixo:


<b> Nota</b>:  <span>Certifique-se de ter git instalado, caso não tenha chame a função de install do seu gerenciador de pacotes e passe o pacote do git.</span> <p>Exemplo com o <b>APT</b>: sudo apt install git</p>

#### Comandos:
```
1. git clone https://github.com/Duck1201/sistema_bancario_anderson.git
2. cd sistema_bancario_anderson
3. ./programa
```

<b> Nota</b>:  <span>Se mesmo assim você não conseguir executar.</span>
Tente: 
```
1. chmod +x programa
2. ./programa
```
